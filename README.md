# Liyou Zhou — Academic Portfolio

Personal academic portfolio website hosted on GitHub Pages at [https://liyouzhou.github.io](https://liyouzhou.github.io).

## Structure

- `index.html` — Single-page academic portfolio (Bio, Selected Publications, Projects & Ongoing Research, Industry Experience, Education)
- `styles.css` — Clean, minimal static stylesheet with no animations or frameworks
- `assets/images/` — Portrait photo and paper/project teaser figures
- `favicon.svg` — Minimal monogram favicon
- `.nojekyll` — Disables Jekyll processing on GitHub Pages

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
